# App_asset_management
Repository untuk pembuatan project aplikasi Asset Management
Aplikasi ini dirancang untuk mempermudah pemantauan aset investasi yang dimiliki oleh user dari berbagai macam instrumen investasi. Aset yang di input oleh user akan otomatis terkalkulasi (keuntungan/kerugian) berdasarkan harga beli/rata-rata dengan harga pasar saat ini.
